ONROAD ILLUSTRATIONS - prompts for generation
==============================================

Where to put the results: this folder (onroad/design/illustrations/), using the exact file names below.
Format: PNG with a transparent background.
Size: 1536x1024 (landscape) unless marked "square" (1024x1024).
Keep the same characters across images if your tool allows (the same young woman and the same young man).

SHARED STYLE - add this to the end of every prompt
--------------------------------------------------
Soft 3D clay-render illustration, premium and minimal, in the style of a modern Indian car-buying / fintech app.
Rounded friendly shapes, soft studio lighting, gentle shadows, matte materials. Palette: warm white, light grey,
charcoal, with vivid orange #F2441F as the only accent colour. Indian characters with natural skin tones and modern
casual clothes. No text, letters, numbers, rupee/dollar signs, logos or watermarks. Transparent background, subject
centred with generous empty space around it.
